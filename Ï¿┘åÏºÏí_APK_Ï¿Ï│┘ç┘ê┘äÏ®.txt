المرحلة الأخيرة: بناء ملف APK

مهم: لم يُنتج ملف APK داخل هذه المحادثة؛ لأن بيئة التنفيذ هنا لا تحتوي Android SDK ولا Gradle. أُضيف للمشروع إعداد GitHub Actions لبناء APK على خادم بناء سحابي.

الخطوات المطلوبة مرة واحدة:
1) حمّل ملف ZIP وفك ضغطه.
2) افتح github.com وأنشئ حساباً أو سجّل الدخول.
3) أنشئ مستودعاً جديداً باسم SijilAlQadaya.
4) ارفع محتويات مجلد SijilAlQadaya_Android_Project إلى المستودع، مع المجلد المخفي .github وملف workflow الموجود داخله.
   - إذا لم يظهر .github في مدير الملفات، فعّل إظهار الملفات المخفية أو ارفع الملفات عبر صفحة GitHub على الويب.
5) بعد اكتمال الرفع، افتح تبويب Actions.
6) اختر Build Android APK. إذا لم يبدأ البناء تلقائياً، اختر Run workflow.
7) انتظر حتى تظهر علامة نجاح خضراء.
8) افتح عملية البناء الناجحة، ثم قسم Artifacts، وحمّل sijil-alqadaya-debug-apk.
9) فك ضغط الملف الناتج. ستجد app-debug.apk.
10) انقل APK إلى هاتف Android واضغط عليه للتثبيت، واسمح بالتثبيت من هذا المصدر إذا طلب الهاتف ذلك.

بديل عبر Android Studio:
1) افتح مجلد المشروع.
2) انتظر Gradle Sync.
3) اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
4) الناتج: app/build/outputs/apk/debug/app-debug.apk.

خصائص المشروع:
- التطبيق مصمم للعمل محلياً دون إنترنت بعد تثبيته.
- لا يحتوي على ماكرو أو VBA.
- البيانات تحفظ محلياً داخل التطبيق.
- تصدير القضايا CSV لفتحها في Excel، والطباعة/الحفظ PDF من خدمة الطباعة في Android.
- احتفظ بنسخة CSV دورية؛ حذف بيانات التطبيق أو إلغاء تثبيته قد يؤدي إلى فقدان البيانات المحلية.

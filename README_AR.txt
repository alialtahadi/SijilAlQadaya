# مشروع سجل القضايا للأندرويد

هذا مشروع Android Studio أولي قابل للبناء إلى APK. يعمل دون اتصال بالإنترنت:
- واجهة عربية RTL قريبة من التصميم المرفق.
- تخزين محلي على الهاتف باستخدام WebView localStorage.
- إضافة وتعديل وحذف القضايا.
- إضافة جلسات وقرارات متعددة لكل قضية.
- تصدير بيانات القضايا بصيغة CSV المتوافقة مع Excel.
- طباعة/حفظ PDF من شاشة التطبيق عبر خدمة الطباعة في Android.

## البناء إلى APK
1. فك ضغط الملف.
2. افتح مجلد `SijilAlQadaya_Android_Project` بواسطة Android Studio.
3. اسمح بمزامنة Gradle وتنزيل مكونات Android SDK المطلوبة.
4. من القائمة: Build > Build Bundle(s) / APK(s) > Build APK(s).
5. ستجد APK عادة في `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات
- المشروع لا يحتوي على ماكرو أو VBA ولا يحتاج صلاحية إنترنت.
- CSV يفتح في Excel ويمكن استيراده كجدول. يمكن إضافة تصدير XLSX أصلي في إصدار لاحق.
- البيانات محفوظة محلياً داخل التطبيق؛ حذف التطبيق أو بياناته قد يحذف السجل. أضف تصديراً احتياطياً بشكل دوري.
- هذا مشروع مصدر وليس ملف APK مبنياً؛ يلزم Android Studio لبناء APK.


## استخراج APK تلقائياً
أضفنا سير عمل GitHub Actions في `.github/workflows/build-apk.yml`.
بعد رفع المشروع إلى مستودع GitHub، افتح Actions وشغّل "Build Android APK".
عند نجاح البناء نزّل ملف `sijil-alqadaya-debug-apk` من قسم Artifacts.
راجع الملف `بناء_APK_بسهولة.txt` للتعليمات خطوة بخطوة.


راجع الملف `بناء_APK_بسهولة.txt` لتنفيذ البناء النهائي على GitHub Actions أو Android Studio. لم يتم تضمين APK مبني في هذه الحزمة.

إضافات الإصدار 1.1:
- دعم الريال اليمني والريال السعودي لكل قضية.
- تسجيل دفعات الأتعاب المتعددة وعرض المدفوع والمتبقي وسجل الدفعات.
- تذكير محلي بموعد الجلسة في الساعة 4:00 مساءً من اليوم السابق.
- يجب السماح بإشعارات التطبيق، والسماح بالتنبيهات الدقيقة من إعدادات أندرويد عند ظهور الطلب.
- تبقى البيانات محفوظة محلياً داخل التطبيق، ولا يحتاج التطبيق إلى الإنترنت.
ملاحظة: رمز ميزان العدالة في رأس التطبيق رمز بصري مؤقت، وليس الشعار الرسمي المصوّر للوزارة.
